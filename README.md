# A po pijmë një kafe? ☕

Një faqe e vogël dhe argëtuese për ta ftuar dikë në kafe.

- **Po** rritet sa herë që dikush provon të klikojë **Jo**.
- **Jo** ikën nëpër ekran dhe nuk pranohet kurrë.
- Pas **Po**: zgjidhet data, ora dhe vendi, pastaj del një timer deri në takim dhe mesazhi për WhatsApp.

Hape `index.html` në shfletues, ose aktivizo GitHub Pages për ta dërguar si link.
